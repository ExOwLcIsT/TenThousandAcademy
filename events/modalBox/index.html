Модальне вікно на EventEmitter

Кнопки не викликають модалку напряму — вони лише емітять події modal:open / modal:close. Сама модалка про них нічого не знає, вона просто підписана слухачем.

Заголовок модалки

Цей блок відкрився через emitter.emit('modal:open'). Закрити можна хрестиком, кнопкою нижче, кліком по фону або клавішею Esc — усі вони просто викликають emitter.emit('modal:close').
